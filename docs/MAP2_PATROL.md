## 配置与执行一致性

- 点位：`backend/app/config/yuntuo/waypoints.json`；路线：同目录 `patrol_routes.json`。
- 路线带 `map_id` 和 `home_waypoint_id`，所有点与回程起点必须属于同一张图。
- `/api/waypoints` 在原 `data` 外增加 `patrol_routes`，沿用现有公网读取入口。
- Web 提交实际选中路线 ID，不再固定提交 `default_patrol`。
- 单独“回家”也按当前地图选择起点；网桥接收并保持该点 ID。
- 语音解析器旧的 `default_patrol` 仍指地图 1；本次没有将这条显式路线重定向成地图 2。
- 更改点位后后端可重新读取；网桥的点位表在启动时加载，需在无任务时重启
  `yuntuo-fpga-bridge`。本次已在导航空闲、零速度且无活动任务时更新并重启。
